  ### 4. Checkpoint lineage and how a new stage registers
  Functions in `checkpoints.py`:
  - `latest_run(conn, cp, stage)` :154
  - `start_run(conn, cp, stage, actor) -> run_id` :160. At cp2 it requires a completed run of the same stage at cp1 and sets `parent_run_id`.
  - `write_tracks(conn, run_id, {entity_key: (weight, payload)}, prefix=None, states=None)` :184. Computes new / held / ±10% / lost against the parent run.
  - `finish_run(conn, run_id, stats)` :212. Supersedes earlier completed runs of the same stage.
  - `run_acquire` :221 is the stage-0 example.
  
  A stage is a free-text value in `checkpoint_run.stage`; there is no registry. The pattern to copy is `areas.run_checkpoint()` (areas.py:112-191):
  1. `ensure(conn)` with its own `CREATE TABLE IF NOT EXISTS`.
  2. `LLM(conn=conn)`.
  3. Get the upstream run with `C.latest_run(conn, cp, "areas")`, raising `CheckpointError` if it is missing.
  4. `BEGIN IMMEDIATE`, then `start_run(cp, "<stage>")`, then COMMIT.
  5. Read the parent rows through `parent_run_id`.
  6. Call the LLM, logging with `log(conn, "<stage>", …, run_id)`.
  7. In one transaction: INSERT rows plus `evidence_edge` rows plus `write_tracks` plus `finish_run`.
  8. Add a CLI `--checkpoint cp1|cp2`.
  9. Add it to `run_all.py`.

  ### 5. LLM wrapper (`src/bmw_req/llm/client.py`)
  ```python
  LLM(conn=None, client=None).generate(*, job: str, tier: Literal["fast","smart"], input: str|list,
      max_output_tokens: int, instructions: str|None=None, schema: type[BaseModel]|None=None,
      reasoning_effort: str|None=None, tools=None, max_tool_calls=None, flex=False, demo=False,
      use_cache=True, **kwargs) -> LLMResult(text, parsed, usage_id, cost_usd, response, cached)
  ```
  - Uses `responses.parse(text_format=schema)` for structured output (:91-92).
  - Results are cached in `llm_cache` by a sha256 of the request (:64-71).
  - `max_output_tokens` is mandatory.
  - Flex rate-limit errors are retried once on standard processing.
  - `LLM.embed(texts, job=)` and `model_for(tier)` are also available.
  
  Model env names (`config.py:35-37`): `OPENAI_MODEL_FAST` (default gpt-6-luna), `OPENAI_MODEL_SMART` (gpt-6.1-sol), `OPENAI_MODEL_EMBED` (text-embedding-3-small).
  
  Budget guard (`llm/budget.py`):
  - Reserve the worst case, then settle in `llm_usage`.
  - WARN at $45, non-demo calls blocked at $70, hard stop at $90.
  - A model without a price in `pricing.py` raises `BudgetExceeded`.
  
  Typical call: `llm.generate(job=f"<stage>:{cp}", tier="smart", instructions=..., input=json.dumps(payload), schema=Model, reasoning_effort="medium", max_output_tokens=20_000, flex=True)`.
